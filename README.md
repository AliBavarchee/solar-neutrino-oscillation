# solar-neutrino-oscillation

A Naïve Python toolkit for simulating **solar and reactor neutrino oscillations** in the three‑flavour framework, including the Mikheyev–Smirnov–Wolfenstein (MSW) matter effect for solar neutrinos and a full JUNO‑like reactor antineutrino + neutron Monte Carlo for medium‑baseline experiments.

---

## Physics

The code computes flavour‑evolution probabilities for neutrinos propagating through matter using the PMNS mixing matrix and a flavour‑basis Hamiltonian of the form

$$
H_f = \frac{1}{2E}\, U \, \mathrm{diag}(0, \Delta m^2_{21}, \Delta m^2_{31}) \, U^\dagger + \mathrm{diag}(V, 0, 0),
$$

with the matter potential $V = \sqrt{2}\,G_F N_e$. Two complementary propagation methods are implemented:

- **Solar neutrinos** — a fixed‑step **first‑order Magnus expansion** (piecewise‑constant Hamiltonian) integrated from the solar core to the surface. This is more robust than adaptive ODE solvers for the stiff, highly oscillatory regime inside the Sun.
- **Reactor antineutrinos at JUNO** — the full three‑flavour vacuum survival probability $P_{\bar ee}$ with the Huber–Mueller reactor spectrum, an improved Vogel–Beacom IBD cross section, and a material‑dependent neutron thermalization Monte Carlo.

## Usage

### Solar neutrino oscillations

Open `PyNeutrinoOssilation.ipynb` in Jupyter and run all cells. The notebook will:

1. Propagate a 10 MeV $\nu_e$ from the solar core to the surface using the Magnus method.
2. Compute averaged probabilities at Earth $P_{ee}$, $P_{e\mu}$, $P_{e\tau}$.
3. Scan over 0.1–100 MeV and compare the numerical $P_{ee}$ with the analytic 2‑flavour MSW approximation.
4. Produce the radial survival probability inside the Sun.

### JUNO reactor + neutron Monte Carlo

```bash
python pyjuno_v3.py --events 50000 --seed 42 --output juno_output
```

Outputs written to `juno_output/`:

- `juno_neutron_events.csv` — all generated events.
- `juno_selected_ibd_events.csv` — IBD‑selected events.
- `JUNO_Neutron_MonteCarlo_Report.pdf` — full multi‑page report.

### ML classification (IBD vs neutron‑only)

```bash
python train_juno_classifier.py
```

Produces `model.pkl`, `model.txt`, `results.json`, `config.json`, and diagnostic plots.

## Highlights

- Real PMNS matrix (CP phase set to zero for simplicity).
- Exponential solar density profile with electron fraction $Y_e = 0.8$.
- Matter potential $V = \sqrt{2} G_F N_e$ computed in eV.
- **Magnus expansion** — unconditionally stable for unitary evolution, no adaptive step‑size failures.
- Huber–Mueller reactor spectrum with U‑235, U‑238, Pu‑239, Pu‑241 fission fractions.
- IBD cross section with recoil and radiative corrections.
- Energy‑dependent neutron elastic cross sections on H and C, capture on H via the 1/v law.
- JUNO‑like detector response: 3% / √E energy resolution, 1345 PE/MeV light yield.
- Asimov $\chi^2$ study of the neutrino mass ordering.
